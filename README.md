You shouldn’t have to choose between agents that plan their own steps, which are flexible,
and predefined workflows, which are predictable. OnRails gives you both.

Your team marks the points of no return, the actions that can’t easily be undone, such as
applying a payment or deploying a release. OnRails holds the agent at each one until its
checks pass. It works at the operating system’s system calls, so the rules hold whichever
tool, script or harness the agent uses.
